## 1. Visión General del Proyecto
**SarangaBaranga** es una aplicación web multimedia e interactiva para la creación, configuración y reproducción sincronizada de **letras de canciones y karaoke**. Opera como una SPA estática sin backend propio alojada en GitHub Pages, con almacenamiento local en el navegador (**IndexedDB**) e intercambio comunitario mediante paquetes JSON y estándar abierto **Lyricsfile (YAML 1.0)**.
