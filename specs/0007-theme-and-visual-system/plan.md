## 1. Conmutación Automática por Sensor de Sistema (`prefers-color-scheme`)
* **Objetivo:** Permitir al usuario elegir "Automático (Sistema)", alternando fluidamente entre un preset oscuro y el preset Minimalista Claro según la configuración del sistema operativo.

## 2. Tipografías Personalizables desde Fuentes Web Locales
* **Objetivo:** Permitir importar fuentes `.woff2` locales mediante FileReader o seleccionar entre una terna de familias optimizadas para lectura de letras (Sans-Serif geométrica, Serif lírica, Monospace rítmica).
